# Image Integration Plan

The site should use a small number of images that explain the business better.
It should not use filler images just because a page looks empty.

## Generate first

1. `home-hero`
   - Page: `index.html`
   - Why: The homepage already has a built image slot with a placeholder graphic.
   - Job: Show the exact kinds of media people bring in one glance.

2. `mixed-media-box`
   - Page: `services.html`
   - Why: The services copy repeatedly mentions mixed boxes and unsorted media.
   - Job: Make the service feel real and approachable.
   - Integration note: Best used after adding one real supporting image block to the page.

3. `transfer-workbench`
   - Page: `about.html`
   - Why: The About page talks about starting with family media and buying better equipment.
   - Job: Back up that story with a believable local workspace photo.
   - Integration note: Best used in the hero side or near the story section.

4. `dvd-and-thumb-drive`
   - Page: `pricing.html`
   - Why: The pricing page already explains DVD versus thumb drive output.
   - Job: Give that choice a concrete visual.
   - Integration note: Best used beside or below the Output Guide section.

## Hold for later

1. `slide-and-photo-scan`
   - Why: Good image, but the current site does not yet have a dedicated scan-focused image area.
   - Risk: If generated now, it is likely to sit unused or feel repetitive next to the mixed-media image.

## Quality bar

1. Every image should show actual media formats the business handles.
2. No people unless we decide the site needs more human presence later.
3. No fake labels, no text inside the image, no logos, no watermarks.
4. Lighting should feel like a real small local business, not luxury product photography.
5. Subjects should stay large and readable so the images still work on mobile.
